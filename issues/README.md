# Issues

Analysis plans and experiment cards live here as one Markdown file each.

- File name: `<number>-<short-title>.md`, e.g. `001-baseline-plan.md`.
- First line after the title: `Labels: analysis-plan | experiment | ready-for-agent` (one or more).
- When an issue is done, add `Status: closed` and a link to the result (notebook, `experiments/LOG.md` entry or commit).
